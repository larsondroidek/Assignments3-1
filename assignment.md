Assignment 3.1 — Two-Page Website with Working Links

What to build: A simple two-page website with working navigation links.

Steps:

1. Create `index.html` and `about.html` files.
2. Create the website name, introduction, and a navigation bar on the home page.
3. Add Home and About links in the navigation.
4. Connect both pages using `<a href="">`.
5. Add a link to any external website as well.
6. Use `target="_blank"` to open the external link in a new tab and `rel="noopener noreferrer"` for security.

Submission: Both HTML files and a screenshot of the working website.
